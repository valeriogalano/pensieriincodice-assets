## Come funziona

Questa repository contiene tutti gli **asset sorgente** utilizzati nella produzione del podcast: frame per le locandine, font, intro audio, musiche di sottofondo e file video. È il punto di partenza per chi vuole contribuire alla grafica o all'identità sonora del podcast.

---

## Struttura della repository

```
/
├── audio/          # File audio (intro, sound tracks, ecc.)
├── covers/         # Frame per le locandine degli episodi
├── fonts/          # Font utilizzati in loghi, locandine, ecc.
├── images/         # Loghi, favicon, immagini varie
├── utils/          # Script di utilità
├── video/          # File video
└── README.md
```
